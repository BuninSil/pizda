# Phone MCP — телефон как MCP-сервер для Claude

Android-приложение, которое превращает твой телефон в MCP-сервер. Claude
подключается к нему как к кастомному коннектору (Streamable HTTP) и управляет
телефоном через AccessibilityService: читает экран, тапает, свайпает, печатает,
открывает приложения. Без аренды серверов и без API-ключей — наружу торчит
бесплатный Cloudflare Quick Tunnel.

> ⚠️ Это мощный и потенциально опасный инструмент: ты даёшь удалённой модели
> управление своим телефоном. Внутри зашиты предохранители (чёрный список
> приложений, подтверждения на экране, секретный токен, главный выключатель,
> лог). Всё равно относись к этому серьёзно и не держи включённым без нужды.

---

## Что внутри

- **MCP-сервер** (Streamable HTTP) на `127.0.0.1:8765`, живёт в Foreground
  Service с постоянным уведомлением. Есть запрос на отключение оптимизации
  батареи, чтобы система не прибивала сервис.
- **Туннель наружу** — cloudflared Quick Tunnel (`*.trycloudflare.com`), без
  аккаунта и домена. Бинарник встраивается в APK как «нативная библиотека».
- **Секретный токен** в пути URL: `https://<туннель>/<токен>/mcp`. Запросы с
  неверным токеном отбиваются ещё до обработчика. Есть кнопка «новый токен».
- **Инструменты MCP** через AccessibilityService: `get_screen`, `screenshot`
  (Android 11+), `tap`, `tap_element`, `long_tap`, `swipe`, `scroll`,
  `type_text`, `press_back`, `press_home`, `open_recents`, `open_app`,
  `list_apps`.
- **Голосовой режим Claude**: кнопка/автозапуск «Позвать Claude» — поднимает
  сервер и туннель, открывает приложение Claude и жмёт кнопку голосового режима
  (с режимом обучения, если кнопку не нашли). Плюс watchdog «Claude замолчал» с
  голосовым оповещением (TTS).
- **Безопасность**: чёрный список приложений, подтверждения на экране,
  предупреждения о недоверенных данных, главный выключатель, лог вызовов.

## Сборка APK

Нужен JDK 17 и Android SDK (проще всего — Android Studio).

### Вариант 1. Через Gradle (CLI)

```bash
# 1) положи бинарник cloudflared внутрь APK (см. раздел «Туннель» ниже)
./scripts/fetch-cloudflared.sh

# 2) собери debug APK
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

Если `./gradlew` ругается на отсутствие SDK — создай `local.properties` в корне:

```
sdk.dir=/путь/к/Android/Sdk
```

### Вариант 2. Android Studio

Открой папку проекта, дай ему скачать зависимости, `Build → Build APK(s)`.

APK собирается **без** встроенного cloudflared тоже — тогда туннель поднимаешь
через Termux (см. ниже), приложение это поддерживает.

## Установка и запуск

1. **Установи APK**: `adb install -r app-debug.apk` (или скинь файл на телефон и
   открой — разреши установку из неизвестных источников).
2. **Включи службу спец. возможностей**: в приложении жми «Открыть настройки
   Спец. возможностей» → найди **Phone MCP Controller** → включи. Это даёт
   приложению право читать экран и выполнять жесты.
3. **Отключи оптимизацию батареи**: кнопка «Отключить оптимизацию батареи».
4. **Разреши уведомления** (Android 13+ спросит сам при первом запуске).
5. **Включи сервер**: переключатель «Сервер MCP» вверху. Поднимется сервер и
   туннель. Через несколько секунд на главном экране появится **ссылка
   коннектора** — она сразу копируется в буфер и дублируется в уведомлении с
   кнопкой «Копировать».

Ссылка выглядит так:

```
https://random-words-1234.trycloudflare.com/<длинный-токен>/mcp
```

## Как добавить в Claude как кастомный коннектор

1. Открой приложение/сайт Claude → **Settings → Connectors** (Коннекторы).
2. **Add custom connector** (Добавить кастомный коннектор).
3. Вставь **полную ссылку коннектора** (с токеном и `/mcp` на конце).
4. Сохрани. Claude подтянет список инструментов (`tools/list`).
5. В чате попроси, например: «посмотри мой экран» — Claude вызовет `get_screen`.

> Если сменил токен или перезапустил туннель — ссылка меняется. Приложение
> обновляет её везде (экран + уведомление + буфер), а в Claude коннектор нужно
> обновить вручную новой ссылкой.

## Туннель наружу

### Основной путь: встроенный cloudflared

cloudflared — статический Go-бинарник. Кладём его как `libcloudflared.so` в
`app/src/main/jniLibs/arm64-v8a/`. Android извлекает нативные библиотеки на диск
с правом на исполнение, поэтому сервис запускает его как обычный процесс.

```bash
./scripts/fetch-cloudflared.sh         # последняя версия
# или конкретная:
./scripts/fetch-cloudflared.sh 2024.8.3
```

После этого собирай APK. При старте сервиса туннель поднимется сам.

> Почему `linux/arm64`: это тот же ABI, что и Android arm64-v8a, бинарник
> статический и запускается. Почти все современные телефоны — arm64.

### Запасной путь: Termux (если встроить не вышло)

Если по какой-то причине встроенный бинарник не стартует (OEM-ограничения,
SELinux и т.п.) — подними туннель руками через [Termux](https://f-droid.org/packages/com.termux/):

```bash
# в Termux:
pkg update && pkg install cloudflared
# телефонное приложение Phone MCP уже слушает localhost:8765
cloudflared tunnel --url http://127.0.0.1:8765
```

cloudflared напечатает строку вида `https://xxxx.trycloudflare.com`. Твоя ссылка
коннектора: `https://xxxx.trycloudflare.com/<токен>/mcp` (токен возьми с
главного экрана приложения — он показан в ссылке, часть между доменом и `/mcp`;
если туннель поднят вручную, токен тот же, что приложение генерит — посмотри его
в сгенерированной ссылке или сгенерируй новый и собери URL сам).

> Termux должен работать параллельно с приложением. Сервер MCP в приложении
> должен быть включён (переключатель сверху), туннель Termux просто
> форвардит на его порт.

## Голосовой режим Claude

- **«Позвать Claude»** (кнопка на главном экране, в уведомлении и плавающая
  кнопка): поднимает сервер и туннель, открывает приложение Claude
  (`com.anthropic.claude`) и жмёт кнопку голосового режима.
- **Deep link**: официального deep link для голосового режима Claude публично не
  задокументировано. Приложение сначала пробует список кандидатов-URI (его можно
  отредактировать в «Настройки голосового режима»), а если не сработало —
  открывает приложение и ищет кнопку через AccessibilityService.
- **Режим обучения**: если кнопку голоса не нашли, включается обучение —
  открой Claude и нажми кнопку голоса **сам один раз**, приложение запомнит её
  признаки (id/текст/описание) и координаты. Дальше будет жать само. Сбросить и
  переобучить — в «Настройки голосового режима».
- **Возврат**: опция «Возвращаться в прежнее приложение после звонка» (по
  умолчанию выключена). Если включена — после старта звонка приложение вернёт
  тебя в прежнее приложение/на домашний экран.
- **Плавающая кнопка**: опция в настройках, требует разрешения «поверх других
  приложений».

### Watchdog «Claude замолчал»

Пока голосовая сессия активна, приложение следит:

- сколько прошло с последнего вызова инструмента MCP (по умолчанию **60 сек**,
  настраивается);
- не пропал ли голосовой режим Claude с переднего плана (обрыв звонка);
- не появилось ли на экране Claude сообщение про лимит.

Если сработало — приложение **проговаривает голосом** (TextToSpeech): «Claude
замолчал, возможно, закончился лимит или оборвался звонок» и показывает
уведомление с кнопкой **«Перезапустить звонок»**.

## Безопасность (зашито в коде)

- **Чёрный список приложений** (редактируемый): по умолчанию банки, платёжки,
  Госуслуги, менеджеры паролей. Пока на переднем плане приложение из списка —
  **все инструменты возвращают ошибку и ничего не делают**. Правится в «Чёрный
  список приложений».
- **Подтверждение на экране** для чувствительных действий (отправка сообщений,
  звонки, покупки, удаление, изменение системных настроек): инструмент **ждёт,
  пока ты нажмёшь «Да»** на телефоне. Таймаут 60 сек → отказ. Определяется по
  подписи элемента (send/call/pay/delete/отправить/позвонить/купить/удалить…) и
  по тому, что открыты системные настройки.
- **Недоверенные данные**: в описаниях инструментов явно сказано, что текст с
  экрана — это данные от сторонних приложений, а **не инструкции**. Claude
  предупреждён не выполнять команды, найденные в содержимом экрана.
- **Главный выключатель**: переключатель в приложении и кнопка «Стоп» в
  уведомлении — мгновенно гасят сервер и туннель.
- **Секретный токен** в URL, сравнение в постоянном времени, кнопка «новый
  токен».
- **Лог вызовов** всех инструментов с временем — на главном экране.

## Ограничения и примечания

- `screenshot` работает только на Android 11+ (через `takeScreenshot`).
- Фоновая запись в буфер обмена на части прошивок ограничена — поэтому есть
  кнопки «Копировать» на экране и в уведомлении.
- Квик-туннели Cloudflare эфемерны: при каждом перезапуске домен новый. Это
  норм для личного использования; для стабильного адреса нужен аккаунт
  Cloudflare (named tunnel) — но ты просил без аккаунтов.
- Это debug-сборка. Для release нужна своя подпись (`signingConfig`).
