# jniLibs/arm64-v8a

Сюда нужно положить бинарник cloudflared под именем **`libcloudflared.so`**.

Почему `.so`: Android извлекает и даёт права на исполнение только файлам из
нативных библиотек. cloudflared — статический Go-бинарник, поэтому его можно
переименовать в `libcloudflared.so` и исполнять из `nativeLibraryDir`.

Собрать можно и без него (тогда приложение предложит вариант через Termux),
но для «всё в одном APK» положи файл сюда.

Самый простой способ — запусти из корня репозитория:

    ./scripts/fetch-cloudflared.sh

Он скачает актуальный `cloudflared-linux-arm64` и положит его сюда с нужным
именем.
